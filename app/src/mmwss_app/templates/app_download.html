Install on your phone

  1. Open this page on your Android phone (use Chrome).
  2. Tap Download APK above.
  3. When prompted, allow Chrome to install unknown apps: Settings → Apps → Special app access → Install unknown apps → Chrome → Allow
  4. Open the downloaded file and tap Install.
  5. Launch Redot Sentinel from your home screen.
  6. Sign in with your MMWSS email + password (and 2FA code if enabled).
  7. When the app asks for notification permission, tap Allow.
